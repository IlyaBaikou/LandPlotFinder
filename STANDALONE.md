# LandPlotFinder: автономная установка

LandPlotFinder работает на одном компьютере и открывается как обычный сайт по
адресу `http://127.0.0.1:8787`. Объявления, настройки и ваши решения хранятся
локально. Google Sheets, Google Cloud, Railway и PostgreSQL не требуются.

## Самый простой вариант

Откройте страницу [LandPlotFinder Releases](https://github.com/IlyaBaikou/LandPlotFinder/releases)
и скачайте файл для своей системы:

- Windows 10/11 — `LandPlotFinder-Windows-Setup-…exe`;
- macOS 11 и новее — `LandPlotFinder-macOS-…dmg`.

Внутри уже находятся Python и все библиотеки. Docker, терминал и ручная
настройка окружения не нужны. Потребуется только интернет для объявлений и карт.

## Установка

### macOS

1. Откройте скачанный `.dmg`.
2. Перетащите LandPlotFinder в папку Applications.
3. При первом запуске нажмите по приложению правой кнопкой → «Открыть» →
   «Открыть». Это требуется, пока приложение не подписано сертификатом Apple.
4. Откроется окно управления, а затем браузер с мастером настройки.

Если пункта «Открыть» недостаточно, откройте «Системные настройки» →
«Конфиденциальность и безопасность» и подтвердите запуск LandPlotFinder.

### Windows

1. Запустите скачанный установщик `.exe`.
2. Если SmartScreen показывает предупреждение, нажмите «Подробнее» →
   «Выполнить в любом случае». Это требуется, пока установщик не подписан.
3. Завершите установку и запустите LandPlotFinder из меню «Пуск».
4. Откроется окно управления, а затем браузер с мастером настройки.

Окно управления можно свернуть. Кнопка «Открыть LandPlotFinder» снова открывает
панель, а «Остановить» корректно завершает локальный сервис.

## Где хранятся данные

Приложение и пользовательская база находятся отдельно. Поэтому обновление или
переустановка программы не удаляют объявления, решения и настройки:

- macOS: `~/Library/Application Support/LandPlotFinder/`;
- Windows: `%LOCALAPPDATA%\LandPlotFinder\`.

В этой папке лежат `landplots.db` и журнал `landplotfinder.log`. Перед переносом
на другой компьютер удобнее воспользоваться кнопкой «Скачать копию» внутри
приложения.

## Первый запуск

Мастер попросит указать:

- максимальную цену;
- минимальную и максимальную площадь;
- максимальное расстояние;
- нужно ли запускать поиск автоматически.

После сохранения начнётся первый поиск. Он может занять несколько минут:
площадки ограничивают частоту запросов, поэтому приложение делает безопасные
паузы. Вкладку браузера можно закрыть — пока открыто окно управления,
приложение продолжит работу.

Полные настройки находятся в разделе «Настройки»:

- несколько независимых профилей поиска;
- несколько поддерживаемых площадок объявлений и электронных торгов;
- отдельная периодичность каждого профиля;
- проверка актуальности ранее найденных объявлений;
- критерии цены, площади, расстояния и электричества;
- выбор Google Maps или Яндекс Карт для открытия точек и маршрутов;
- необязательные Telegram-уведомления.

Для Telegram понадобятся токен собственного бота и ID личного чата или группы.
Подробная инструкция со всеми действиями в BotFather, способом узнать ID и
проверочным сообщением: **[Как подключить Telegram-бота](docs/TELEGRAM.md)**.

## Где находятся результаты

- «Обзор» показывает короткий список и состояние последнего запуска;
- «Объекты» содержит фильтруемый каталог;
- у объекта можно сохранить решение и заметку;
- «Карта» показывает объявления с координатами;
- кнопка маршрута упорядочивает объекты со статусом «К поездке» и открывает их
  в выбранном сервисе — Google Maps или Яндекс Картах;
- «Источники» показывает успешность обходов, повторы, ошибки и признаки
  изменения структуры площадки;
- в подробной карточке доступны график цены и хронология изменений;
- «Скачать CSV» выгружает локальную копию каталога.

Снятое объявление архивируется только после двух последовательных
подтверждений. Ошибка сети, CAPTCHA или ограничение запросов не считаются
подтверждением снятия.

## Обновление

Для desktop-версии скачайте и установите новый `.dmg` или `.exe` поверх старой
версии. База находится отдельно и сохранится. Для Docker-версии замените файлы
проекта и снова запустите `start.command` или `start.bat` — отдельный том с
данными также сохранится.

## Резервная копия

В разделе «Настройки» нажмите «Скачать копию». Приложение создаст согласованный
снимок SQLite, в который входят объявления, история цен и состояний, ваши
решения, профили поиска и расписания.

Для восстановления нажмите «Восстановить из файла» и выберите ранее скачанный
файл `.sqlite3`. Перед заменой базы приложение проверит формат, целостность и
наличие обязательных таблиц. Восстановление недоступно, пока выполняется поиск
или проверка актуальности.

В установленной desktop-версии база хранится в системной пользовательской папке,
указанной выше. В Docker-версии она находится в томе `landplotfinder_data`.

## Docker-вариант для Linux и опытных пользователей

Для этого способа нужен Docker Desktop на Windows/macOS либо Docker Engine с
Compose на Linux. Скачайте репозиторий и запустите `start.command` на macOS/Linux
или `start.bat` на Windows. Приложение соберётся и откроет
`http://127.0.0.1:8787`.

## Полезные команды

```bash
docker compose ps              # состояние
docker compose logs -f         # журнал работы
docker compose restart         # перезапуск
docker compose stop            # остановить, сохранив данные
docker compose down            # убрать контейнер, сохранив данные
```

Не выполняйте `docker compose down -v`, если не хотите удалить всю локальную
базу LandPlotFinder.

## Запуск из исходного кода без Docker

Нужен Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install .
mkdir -p data                   # Windows: mkdir data
DATABASE_URL=sqlite:///./data/landplots.db land-plot-finder-web
```

Затем откройте `http://127.0.0.1:8787`.

## Безопасность

Desktop- и Docker-версии публикуют панель только на `127.0.0.1`: она доступна с
этого компьютера, но не из домашней сети и не из интернета. Если самостоятельно
откроете сервис наружу, сначала добавьте аутентификацию и HTTPS.

Парсер использует только публичные страницы. Не уменьшайте задержки запросов и
учитывайте правила конкретных площадок.
