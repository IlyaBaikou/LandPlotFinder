# LandPlotFinder: автономная установка

LandPlotFinder работает на одном компьютере и открывается как обычный сайт по
адресу `http://127.0.0.1:8787`. Объявления, настройки и ваши решения хранятся
локально. Google Sheets, Google Cloud, Railway и PostgreSQL не требуются.

## Что понадобится

- Windows 10/11, macOS или современный Linux;
- Docker Desktop (Windows/macOS) либо Docker Engine с Compose (Linux);
- интернет для загрузки объявлений и карты;
- около 1 ГБ свободного места на первый запуск.

## Быстрый запуск

### macOS

1. Установите и запустите Docker Desktop.
2. Скачайте папку проекта.
3. Дважды нажмите `start.command`. Если macOS блокирует файл, нажмите по нему
   правой кнопкой → «Открыть».
4. В браузере откроется мастер настройки.

Для остановки дважды нажмите `stop.command`.

### Windows

1. Установите и запустите Docker Desktop.
2. Скачайте и распакуйте папку проекта.
3. Дважды нажмите `start.bat`.
4. В браузере откроется мастер настройки.

Для остановки используйте `stop.bat`.

### Linux

```bash
chmod +x start.command stop.command
./start.command
```

## Первый запуск

Мастер попросит указать:

- максимальную цену;
- минимальную и максимальную площадь;
- максимальное расстояние;
- нужно ли запускать поиск автоматически.

После сохранения начнётся первый поиск. Он может занять несколько минут:
площадки ограничивают частоту запросов, поэтому приложение делает безопасные
паузы. Вкладку браузера можно закрыть — контейнер продолжит работу.

Полные настройки находятся в разделе «Настройки»:

- источники Realt, Kufar и аукционы;
- периодичность поиска;
- проверка актуальности ранее найденных объявлений;
- критерии цены, площади, расстояния и электричества;
- необязательные Telegram-уведомления.

## Где находятся результаты

- «Обзор» показывает короткий список и состояние последнего запуска;
- «Объекты» содержит фильтруемый каталог;
- у объекта можно сохранить решение и заметку;
- «Карта» показывает объявления с координатами;
- «Скачать CSV» выгружает локальную копию каталога.

Снятое объявление архивируется только после двух последовательных
подтверждений. Ошибка сети, CAPTCHA или ограничение запросов не считаются
подтверждением снятия.

## Обновление

Замените файлы проекта новой версией и снова запустите `start.command` или
`start.bat`. Docker пересоберёт приложение, а отдельный том с данными сохранится.

## Резервная копия

Все данные находятся в Docker-томе `landplotfinder_data`.

Создать резервную копию базы в текущей папке:

```bash
docker run --rm -v landplotfinder_data:/data -v "$PWD:/backup" alpine \
  cp /data/landplots.db /backup/landplots-backup.db
```

На Windows ту же операцию проще выполнить через Docker Desktop: Volumes →
`landplotfinder_data` → Export.

## Полезные команды

```bash
docker compose ps              # состояние
docker compose logs -f         # журнал работы
docker compose restart         # перезапуск
docker compose stop            # остановить, сохранив данные
docker compose down            # убрать контейнер, сохранив данные
```

Не выполняйте `docker compose down -v`, если не хотите удалить всю локальную
базу LandPlotFinder.

## Запуск без Docker

Нужен Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install .
mkdir -p data                   # Windows: mkdir data
DATABASE_URL=sqlite:///./data/landplots.db land-plot-finder-web
```

Затем откройте `http://127.0.0.1:8787`.

## Безопасность

Docker публикует панель только на `127.0.0.1`: она доступна с этого компьютера,
но не из домашней сети и не из интернета. Если самостоятельно откроете сервис
наружу, сначала добавьте аутентификацию и HTTPS.

Парсер использует только публичные страницы. Не уменьшайте задержки запросов и
учитывайте правила конкретных площадок.
