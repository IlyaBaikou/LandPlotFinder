# Telegram-уведомления: настройка с нуля

LandPlotFinder может присылать новые и заметно изменившиеся объявления в
личный чат или в общую Telegram-группу. Для этого нужен собственный бесплатный
бот. Webhook, публичный сервер и отдельный Telegram-аккаунт не требуются.

Вся настройка обычно занимает 5–10 минут.

## 1. Создайте бота

1. Откройте в Telegram официального [@BotFather](https://t.me/BotFather).
2. Нажмите **Start** или отправьте команду `/start`.
3. Отправьте команду `/newbot`.
4. Введите отображаемое имя, например `Наш поиск участка`.
5. Придумайте username латиницей. Он обязательно должен заканчиваться на
   `bot`, например `family_land_finder_bot`.
6. BotFather пришлёт токен вида
   `1234567890:AAExampleSecretToken`. Скопируйте его — это значение для поля
   **«Токен бота»** в LandPlotFinder.

> **Важно:** токен равнозначен паролю от бота. Не публикуйте его в GitHub, не
> присылайте посторонним и не оставляйте на скриншотах. Если токен утёк,
> откройте BotFather, выберите `/mybots` → своего бота → **API Token** →
> **Revoke current token**.

## 2. Выберите, куда присылать объявления

### Вариант A: личный чат

1. Откройте созданного бота по ссылке, которую дал BotFather.
2. Нажмите **Start**.

Личный чат удобен, если подборкой пользуется один человек.

### Вариант B: семейная группа

1. Откройте существующую группу или создайте новую.
2. Откройте название группы → **Добавить участников**.
3. Найдите бота по username и добавьте его.
4. Отправьте в группе команду `/start@username_бота`. Например:

   ```text
   /start@family_land_finder_bot
   ```

Обычно делать бота администратором не нужно. Если в группе запрещено писать
обычным участникам, разрешите боту отправлять сообщения или выдайте ему только
это право.

## 3. Узнайте ID чата

Telegram использует числовой ID, чтобы бот понимал, куда отправлять сообщения.

1. Подставьте полученный токен вместо `ВАШ_ТОКЕН` в адрес:

   ```text
   https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
   ```

2. Откройте получившийся адрес в браузере.
3. Найдите фрагмент `"chat"`, а рядом с ним поле `"id"`.

Для личного чата ответ будет похож на:

```json
"chat": {"id": 123456789, "first_name": "Анна", "type": "private"}
```

Для группы — на:

```json
"chat": {"id": -1001234567890, "title": "Ищем участок", "type": "supergroup"}
```

Скопируйте число из `id` целиком. Минус в начале ID группы обязателен.

Если в ответе написано `"result": []`, вернитесь в нужный чат, ещё раз
отправьте `/start` или `/start@username_бота`, а затем обновите страницу.
Убедитесь, что смотрите запись с названием именно вашей группы: в ответе могут
одновременно находиться личный чат и несколько групп.

## 4. Заполните настройки LandPlotFinder

1. Откройте LandPlotFinder.
2. Перейдите в **Настройки** → **Telegram**.
3. Включите **«Присылать уведомления»**.
4. Вставьте секретный токен в поле **«Токен бота»**.
5. Вставьте найденное число в поле **«ID чата»**.
6. Нажмите **«Сохранить настройки»**.

Настройка общая для всех профилей поиска.

## 5. Проверьте бота

Чтобы сразу проверить токен и ID, подставьте их в адрес ниже и откройте его в
браузере:

```text
https://api.telegram.org/botВАШ_ТОКЕН/sendMessage?chat_id=ID_ЧАТА&text=LandPlotFinder%20подключён
```

Если всё настроено правильно, в выбранном чате появится сообщение
`LandPlotFinder подключён`.

После этого запустите поиск в LandPlotFinder. Сервис уведомляет только о новых
или существенно изменившихся подходящих объявлениях, поэтому сразу после
сохранения настроек сообщение может не появиться.

## Если не работает

| Что видно | Что проверить |
|---|---|
| `Unauthorized` | Токен скопирован не полностью или был отозван. Получите актуальный токен в BotFather. |
| `chat not found` | Проверьте ID, включая минус в начале, и убедитесь, что бот добавлен в нужную группу. |
| `bot was blocked by the user` | Откройте личный чат с ботом и нажмите **Start**. |
| `bot is not a member of the supergroup` | Повторно добавьте бота в группу. |
| Тест работает, но подборки нет | Запустите поиск и дождитесь нового или существенно обновлённого подходящего объявления. |
| В группе бот молчит | Проверьте, разрешено ли ему отправлять сообщения. Полные права администратора обычно не нужны. |
